# Example: Login flow

A minimal template showing the test step format.
Each step is a plain English instruction — no selectors, no coordinates.
The run-test skill resolves UI elements at runtime via dump_ui.

## Steps

1. Open the app
2. Tap the "Email" field and enter "user@example.com"
3. Tap the "Password" field and enter "secret123"
4. Tap the "Login" button
5. Wait for the home screen to appear
6. Verify the user's name is visible on screen
